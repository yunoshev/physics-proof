# Task M3 — SAM 3.1 tool

Spec: `SPEC.md` §3 "M3. SAM 3.1 tool". Build only this module and its tests. Done modules to reuse (do not rewrite):
`physics_proof/meta_client.py` (`MetaClient.sam_video` → `SamResult`), `physics_proof/video.py` (`probe`,
`read_frames`, `contact_sheet` with its `overlay` callback), `physics_proof/blocks.py` (`save_masks`, `load_masks`,
`MaskSet`, `mask_stats`, `track_quality`), `physics_proof/ledger.py`.

## Build `physics_proof/sam_tool.py`
- `SamTool(client, workspace, clip_path, *, budget_frames=1500, cache_dir=None)` and
  `SamTool.run(phrase, start, stop) -> SamToolResult`, the tool the agent calls as `sam(phrase, start, stop)`:
  - `phrase` is one short noun phrase (validate: 1–4 words, letters/spaces/hyphens only); `0 ≤ start < stop ≤ frames`.
  - **Only the requested frames are sent:** cut the clip to frames `start..stop-1` frame-accurately (select by frame
    index and re-encode; never seek by time), send that, then map the returned frame numbers back by `+start`.
    SAM bills at least 50 frames per request; note it in the result when the range is shorter.
  - Save `workspace/sam/<phrase-with-underscores>.<start>-<stop>.npz` with `blocks.save_masks` (full-frame masks of
    the original clip size).
  - **Cache:** key = (sha256 of the clip file, phrase, start, stop) in `cache_dir` (default `cache/sam/` in the repo,
    git-ignored). An identical call makes no API call. A call whose range lies inside a cached longer range for the same
    phrase is cut from it with no API call.
  - **Budget:** frames per clip counted as `stop − start` over all non-cached calls; a call that would exceed
    `budget_frames` is refused with a clear one-line message and makes no API call.
  - **Result** (`SamToolResult`): `npz` path, `sheet` path, `objects` (per object id: confidence, frames present /
    total, median area, bbox range, `track_quality` summary), `identity_swaps` (frames where an object's centroid jumps
    by more than its own bbox diagonal between neighbouring frames — a likely id swap), `frames_billed`, `cost_usd`,
    `cached` (bool), and `text()` — a compact plain-text summary for the agent (≤ 1 500 characters).
  - **Overlay sheet** `workspace/sam/<…>.png`: up to 24 frames spread evenly over the range, each object tinted in its
    own colour with its id, built with `video.contact_sheet(..., overlay=...)`.

## Probes (tests)
Offline (`uv run pytest`), with a fake client that serves the recorded SAM fixture or synthetic masks:
1. Frame-accurate cut: on the synthetic digit clip (as in the M2 tests), cutting 30..60 gives 30 frames and frame 0 of
   the cut shows digit 30; returned frame numbers map back to 30..59.
2. Cache: the second identical call makes no client call; a sub-range (40..50 after 30..60) makes no client call and
   its masks equal the slice of the cached ones.
3. Budget: with `budget_frames=100`, calls of 60 and then 50 frames → the second is refused, no client call.
4. Result: `npz` round-trips through `blocks.load_masks`; the sheet exists; each object's bbox in the summary matches
   the masks; a planted id swap (two objects exchange places at one frame) is reported in `identity_swaps`.
5. Phrase validation rejects `""`, `"a b c d e"`, `"car; rm -rf"`.
API (`-m api`, ≈ $0.01): one real call on the synthetic red-square clip (`tests/fixtures/sam_clip.mp4`), range 2..8:
masks on those frames, `frames_billed` reported, ledger line written, then the same call again hits the cache.
