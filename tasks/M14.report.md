## Probe coverage
- Passing probe registers; registry entry holds name, purpose, functions, probe source/output, turn, attempt; later `python` imports it (`test_passing_probe_registers_and_imports`,incl. version files and overwritten bogus `tools`).
- Failing probe returns its output, module stays unregistered and not importable (review refuses the import too).
- Banned import (`socket`) refused by review; marker file proves the probe never ran; attempt still counted.
- Limits: `max_tools=2` blocks the 3rd tool; `tool_attempts=2` blocks the 3rd try on one name. Re-register replaces (latest wins) and keeps all versions; tools can import each other.
- `finish` fills `tools` (`verified: true`); a tool-less run has no `tools` key; malformed entries rejected by path.
- `promote_tool` writes both files; the generated test passes under pytest (also verified once through the real CLI, then removed).
