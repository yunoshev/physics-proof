# Task M1 — Meta API client and cost ledger

Spec: `SPEC.md` §3 "M1. Meta API client" and §7 (prices, caps). Build only this module plus its tests and the project
scaffolding (`pyproject.toml`, package, test setup).

## Facts about the API (measured on 2026-10-27 against `https://api.meta.ai/v1`)

**Spark — `POST /v1/responses`**
- Body: `model`, `input` (list of messages; content parts `input_text`, `input_image`, `input_video` with
  `video_url` as a `data:video/mp4;base64,…` URL for files ≤ 50 MB, or a `file_id` from the Files API), `instructions`,
  `tools`, `text.format` (JSON schema output), `reasoning: {"effort": "low"|"medium"|"high"}`, `max_output_tokens`,
  `store`, `include`, `previous_response_id`, `stream`. `stream: true` must be sent explicitly.
- Reasoning tokens count as output and are large even at `low` (≈ 700–1000 for a short answer). With
  `max_output_tokens: 16` the response comes back `status: "incomplete"`. Default `max_output_tokens` should be generous
  (e.g. 4096) and the client must surface `incomplete` clearly.
- Video input costs ≈ 121 tokens per second of video (15.5 s clip = 1876 input tokens).
- **Tool calling:** `tools: [{"type":"function","name":…,"description":…,"parameters":{JSON schema},"strict":true}]`.
  `tool_choice` accepts only `"auto"`. With `strict: true` the schema must have `additionalProperties: false` and list
  every property in `required`, otherwise HTTP 400. Output items of a turn: `reasoning` (id `rs_…`), a `message` with
  `phase: "commentary"`, then `{"type":"function_call","id":"fc_…","call_id":"call_…","name":…,"arguments":"<JSON string>","status":"completed"}`.
  The result goes back as `{"type":"function_call_output","call_id":…,"output":"<string>"}`, either with
  `previous_response_id` (server stores the turn) or statelessly with `store: false`,
  `include: ["reasoning.encrypted_content"]` and the previous output items sent back verbatim.
- Streaming events used: `response.output_text.delta`, `response.output_item.added`,
  `response.function_call_arguments.delta` / `.done`, `response.output_item.done`, `response.completed` (carries the
  full response object with `usage`: `input_tokens`, `input_tokens_details.cached_tokens`, `output_tokens`,
  `output_tokens_details.reasoning_tokens`). Use the `response.completed` object as the source of truth.
- Rate-limit headers: `x-ratelimit-limit-requests`, `x-ratelimit-limit-tokens`.

**Files — `POST /v1/files`** multipart, `purpose=user_data`, `expires_after[anchor]=created_at`,
`expires_after[seconds]=3600` → `{id, bytes, created_at, expires_at, status}`. `DELETE /v1/files/{id}` → 200.

**SAM 3.1 — `POST /v1/responses`**, `model: "sam-3.1"`, `stream: true`, one user message with `input_text` = one noun
phrase and `input_video` (`file_id` or data URL); `metadata: {"include_confidence": "true", "mask_encoding": "lossless"}`
(values are strings). The stream sends one text line per frame that has objects:
`<Nf>id<|box;x1;y1;x2;y2;w;h;c|><|mask;x=0;y=0;c;data=H,W,~payload|>,id…`. The mask is a crop the size of the box,
placed at (x1, y1). Frames without objects send no line. The same full text is repeated in four final events
(`output_text.done`, `content_part.done`, `output_item.done`, `completed`) — parse it once. `response.completed` has
`usage.video_frames_processed`. Decode masks with Meta's package `meta-sam-parser` (import `meta_sam_parser`; it has
`parse_responses_stream`, `video_segmentation_format`, `decode_mask_to_raster`; inspect it, do not write your own decoder).
Speed: 466 frames in ≈ 30 s.

**Errors:** HTTP 402 `{"error":{"code":"billing_not_configured","message":…,"type":"billing_error"}}`; 400 with
`error.message` and `param`; 429 and 5xx are transient.

**Prices** (per 1M tokens unless stated) — put them in `config/prices.json`, not in code:
`muse-spark-1.3` in 1.25 / out 4.25 · `muse-spark-1.3-contributor` 0.10 / 0.20 · `web_search` 2.50 per 1k calls ·
`sam-3.1` 0.20 per 1k video frames, 2.50 per 1k images. Cached input tokens: charge at the input price (we do not know
a discount).

## Build
- `physics_proof/config.py` — settings: base URL, default Spark model (`muse-spark-1.3-contributor`), default effort,
  default `max_output_tokens`, price table path, ledger paths. Overridable by environment variables.
- `physics_proof/ledger.py` — `Ledger(run_path, global_path)`: `add(record)` appends one JSON line to both files
  (`ts, run, model, kind, input_tokens, cached_tokens, output_tokens, reasoning_tokens, frames, searches, usd, note`);
  `total(path)` sums `usd`; cost is computed from the price table.
- `physics_proof/meta_client.py` — `MetaClient`:
  - `respond(input, *, model=None, instructions=None, tools=None, json_schema=None, effort=None, web_search=False,
    previous_response_id=None, store=False, include=None, max_output_tokens=None, note="") -> SparkResponse`
    (streams; returns id, status, output items, text, parsed function calls with `arguments` as a dict, usage, cost);
  - helpers that build content parts: `text_part`, `image_part(path)`, `video_part(path)` (data URL ≤ 50 MB, otherwise
    upload and use `file_id`);
  - `upload_file(path, expires_s=3600) -> str`, `delete_file(file_id)`;
  - `sam_video(video_path, phrase, *, mask_encoding="lossless") -> SamResult` (uploads, streams, decodes, deletes the
    file even on error): `frames: dict[int, list[SamObject]]` with `id`, `box`, `confidence`, full-frame boolean `mask`
    (numpy, H×W of the video), plus `frames_processed` and cost;
  - retries: 429 and 5xx up to 3 attempts with backoff (respect `Retry-After`); 402 → `BillingError` with one clear
    line naming the Billing page, never retried; 4xx → `ApiError(status, message, param)`; broken stream → `StreamError`.
  - every call adds one ledger record.
- `scripts/record_fixtures.py` — makes three real calls and saves their raw SSE streams to `tests/fixtures/`:
  a short Spark text answer, one Spark turn that calls a tool, and SAM 3.1 on a synthetic 10-frame clip (a red square
  moving on a grey background, generated with ffmpeg lavfi, phrase "red square"). Prints the total cost. Must cost < $0.01.

## Probes (tests)
Offline (`uv run pytest`):
1. A local fake server (stdlib `http.server` in a thread) returns 402 → `BillingError`, exactly one request made.
2. 429 then 200 → success after one retry; four 500s → `ApiError` after 3 attempts.
3. A truncated / malformed SSE stream → `StreamError`.
4. The recorded Spark fixtures parse: text extracted; the tool turn yields one function call with dict arguments.
5. The recorded SAM fixture decodes: masks are boolean, full-frame sized, inside their boxes; frame count matches.
6. Ledger: costs for a set of hand-written usages equal a hand-computed table; totals add up.
7. With `META_API_KEY=sk-test-SECRET-123`, no file under the run directory and no captured log/exception text contains it.

API (`uv run pytest -m api`, < $0.01 total): one Spark call with `max_output_tokens` ≥ 512 returns `completed` and a
ledger line; one SAM call on the synthetic clip returns masks on most frames and `frames_processed` > 0.
