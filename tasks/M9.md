# Task M9 — analysis schema and validator

Spec: `SPEC.md` §3 "M9", §2 Principles 5–6, §5 (both cases). Build only this module and its tests. Reuse
`physics_proof/blocks.py` (`decide`, `spans_of`) — never re-implement the verdict.

Why: this is the contract between Spark (who writes `analysis.json` during a run) and the page. The validator is what
stops a run from publishing numbers that do not add up.

## Build
1. `config/analysis.schema.json` — JSON Schema (draft 2020-12), version 1, `type: "world-g"`. Sections:
   - `clip`: file, fps, frames, width, height, duplicates found, notes.
   - `context`: scene, claim, expected values `[{quantity, value, unit, source}]`, sources (URLs).
   - `first_look`: what, where, when, source, confidence 0..1, `by_eye {quantity, value, unit}`.
   - `reference`: list (≥ 1) of `{name, extent, value_m, tolerance_m, source_url, quote, source_type
     (primary|secondary|estimate), mask {file, object}, mask_check {verdict, covers}}`. `source_url`/`quote` may be null
     only when `source_type` is `estimate`.
   - `scale`: `frame, extent_px, extent_px_err, m_per_px, m_per_px_err, second {name, m_per_px, m_per_px_err,
     agree_sigma} | null, frame_of_reference` — either `"image"` or `{object, anchor (top|bottom), size_px_per_frame}`
     for a moving camera (positions are then in reference sizes and `m_per_ref` replaces `m_per_px`).
   - `track`: `what, method, unit (px|ref), points [{frame, x, y}]`.
   - `masks`: `{object_name: {frame: spans}}` — only frames the page draws (`blocks.spans_of` format).
   - `flights`: list (≥ 1) of `{kind (flight|wall), start, apex|null, end, rise_m, duration_s, fit {a, a_err, rms, v0,
     n, window}, accel, accel_err (m/s², down positive), hypothesis {name, value}, decide {…}, ghost [{frame, y}],
     notes}`.
   - `timescale`: `null` or `{method, value, err, unit, expected_range [lo, hi], verdict (normal|slow|fast|undetermined)}`.
   - `error_budget`: `{term: relative error}`.
   - `verdict`: exactly the dict `blocks.decide` returns for the combined measurement, plus `g`, `g_err`, `worlds`.
   - `overall`: `{label, text}` — see 3.
   - `page_texts`: optional `{key: string}` overrides for any text on the page.
   Unknown fields are allowed and ignored.
2. `physics_proof/schema.py`: `validate(analysis, *, clip_frames=None, fps=None) -> list[Issue]`, `Issue(path, message)`
   with JSON-pointer-like paths (`/flights/0/fit/a_err`). Checks: required fields; types; ranges (frames inside the
   clip, errors > 0, confidence 0..1); internal consistency — `duration_s == (end − start) / fps` within half a frame;
   `rise_m` matches the track (start − apex or start − end in track units × scale) within 2 % or 0.02 m; each
   `flights[i].decide` and the top-level `verdict` recomputed with `blocks.decide` must match (`state`, `consistent`,
   `k` within 1e-6); `overall` must match `combine(...)`.
3. `combine(verdict, timescale) -> {label, text}` — deterministic: `fits:<world>` → that world; `undetermined` →
   undetermined; `none_fits` with `timescale.verdict == "normal"` → `impossible` ("the motion ignores gravity at normal
   speed"); `none_fits` with no or undetermined timescale → `none_fits` with the playback factor from `decide`;
   `none_fits` with `timescale.verdict` slow/fast consistent with `k` (within its error) → `retimed` (slowed / sped up by
   k). English texts, one sentence each.
4. `schema_doc() -> str` — a compact description of the schema for the agent's system prompt (≤ 4 000 characters),
   generated from the schema file so the prompt and the validator never drift.

## Probes (tests, offline)
Fixtures are synthetic scenes, **not** the Moon or the wall clip (fixtures may end up as examples in prompts):
`tests/fixtures/analysis_ball.json` (a ball tossed on Earth, image frame, fits Earth) and
`tests/fixtures/analysis_ramp.json` (a skater rolling up a vertical ramp, moving camera, `kind: wall`, measured 4.0 ± 0.5
vs 9.81, timescale normal → `impossible`). Both must be internally consistent.
1. Both fixtures validate with no issues.
2. Removing each required field in turn (generate the list from the schema) gives an issue naming that exact path.
3. A tampered `verdict.state`, a tampered `flights[0].decide.k`, a wrong `duration_s`, a wrong `rise_m`, a frame outside
   the clip, and a wrong `overall.label` are each rejected with a readable message.
4. `combine` table: the five cases above.
5. `schema_doc()` ≤ 4 000 characters and mentions every top-level section.

Offline tests pass (old and new); `tasks/M9.report.md` written.
