# Task M6 — Physics blocks (verified library)

Spec: `SPEC.md` §3 "M6. Physics blocks" and §4 (rules of evidence). Build only this module and its tests. The agent's
sandboxed code will `import blocks`, so every function needs a docstring that states argument shapes, units and returns.
M1 (API client) and M2 (`physics_proof/video.py`) are done. No API calls in this task.

## Build `physics_proof/blocks.py` (and a thin top-level `blocks.py` shim that re-exports it)
- **Mask file format** (M3 will write it, you define it): `save_masks(path, frames, ids, masks, confidence)` /
  `load_masks(path) -> MaskSet`. One compressed `.npz`: `frames` int32[N] (frame indices), `ids` int32[K],
  `masks` bool[N, K, H, W], `present` bool[N, K], `confidence` float32[K]. `MaskSet.of(obj_id) -> bool[N, H, W]`,
  `MaskSet.frames`, `MaskSet.ids`. Passing a `MaskSet` or a dict where a single-object array is expected (or the other way
  round) raises a `TypeError` that says which one was expected — never a raw numpy error.
- `video_info`, `read_frames`: re-export from `physics_proof.video`.
- `mask_stats(obj_masks) -> list[dict]` per frame: `area`, `bbox` (x1, y1, x2, y2), `centroid` (x, y), `top_y`,
  `bottom_y` (lowest mask pixel — the feet/bottom of the body, rule 3), `left_x`, `right_x`; empty frames give `None`.
- `largest_component(mask) -> mask` (4-connected; `scipy.ndimage` is allowed).
- `spans_of(mask) -> list[[y, x0, x1]]` row runs (x1 exclusive) for drawing masks on the page; `spans_of_track(obj_masks,
  frames) -> dict[int, list]`.
- `track_quality(obj_masks, frames, *, area_jump=1.5, split_ratio=0.2) -> dict`: flags `gaps` (frames with an empty mask
  or missing indices), `area_jumps` ([frame, ratio] where area changes by more than `area_jump`× between neighbours),
  `splits` (frames where the second-largest component is ≥ `split_ratio` of the largest), and a `summary` line.
- `fit_parabola(frames, y_px, fps) -> dict`: least squares `y = a·t² + b·t + c` with `t = frame / fps` (seconds);
  image y grows downwards, so falling has `a > 0`. Returns `g_px` = 2a (px/s²), `g_px_err` (from the fit covariance),
  `rms` (px), `residuals`, `apex_t`, `apex_y`, `v0_px`, `n`, and the window used. Needs ≥ 5 points.
- `scale_from_reference(length_px, length_px_err, size_m, size_m_err) -> (px_per_m, err)` and
  `to_metres(g_px, g_px_err, px_per_m, px_per_m_err) -> (g, g_err)`: relative errors added in quadrature.
- `decide(g, g_err, worlds=None, *, k_sigma=2.0) -> dict`: default worlds Earth 9.81, Moon 1.62 (Mars 3.71 only if passed).
  For each world `sigma = (g − g_world) / g_err`; a world is consistent when |sigma| ≤ `k_sigma`.
  - exactly one consistent → `state = "fits:<World>"`;
  - two or more consistent → `state = "undetermined"` (error too large to separate them);
  - none consistent → `state = "none_fits"`, `nearest` = the world with the smallest |ln(g / g_world)|, and
    `k = sqrt(g_world / g)` (k > 1: the clip runs slow by ×k; k < 1: it runs fast).
  Also returns per-world sigmas and a one-sentence English `text` for the page.

## Probes (tests, offline)
1. Synthetic parabolas: 200 trials, known g in px/s², 30 fps, 30–45 points, Gaussian pixel noise σ = 1.5 px. The true
   value lies within 1σ of `g_px` in ≥ 66 % of trials (≈ 68 % expected), and the mean reported `g_px_err` matches the
   standard deviation of `g_px` across trials within 20 %. Fixed random seed.
2. `decide` — these hand cases must match exactly (plus at least 6 more of your own, each with the arithmetic written in
   a comment):
   | g | g_err | expected |
   |---|---|---|
   | 1.60 | 0.10 | fits:Moon |
   | 9.70 | 0.40 | fits:Earth |
   | 0.72 | 0.05 | none_fits, nearest Moon, k = 1.500 ± 0.001 |
   | 4.36 | 0.30 | none_fits, nearest Earth, k = 1.500 ± 0.001 |
   | 5.00 | 3.00 | undetermined |
   | 2.02 | 0.20 | fits:Moon (sigma 2.0 is consistent; compare with a 1e-9 tolerance) |
   | 2.03 | 0.20 | none_fits, nearest Moon, k < 1 |
3. `track_quality` on a synthetic moving disc: flags a planted gap (empty frames 10–11), a planted area jump (frame 20
   doubled), and a planted split (frame 30 has a second blob 30 % of the main one); a clean track has no flags.
4. `mask_stats.bottom_y` equals the lowest row of a synthetic mask; `largest_component` drops a small blob.
5. `save_masks` → `load_masks` round-trips exactly; `MaskSet.of` returns the right object; wrong argument types raise
   the clear `TypeError`.
6. `scale_from_reference` / `to_metres`: a hand-computed example (e.g. 120 ± 2 px for 1.50 ± 0.03 m) matches.
7. Every public function has a docstring that mentions shapes and units (test by introspection).
