# Task E1 — acceptance clips and the eval checker

Spec: `SPEC.md` §5 (Acceptance: the Moon, and the second clip), Principle 7 (blindness). Build only this; do not touch
the agent modules.

## Build
1. `scripts/make_moon_clips.py`: download `a16salute.mpg` from the Apollo Lunar Surface Journal (the page and file are
   named in `SPEC.md` §5; find the exact file URL on that page), check the download (size, decodable), and write:
   - `examples/moon/A.mp4` — re-encoded to H.264 (yuv420p, CRF 18), no audio, no metadata (`-map_metadata -1`), same
     frame rate as measured by `physics_proof.video.probe` (the container's declared rate may be wrong — use the measured
     one);
   - `examples/moon/B.mp4` — the same clip slowed ×1.5 with motion interpolation back to A's frame rate
     (`setpts=1.5*PTS,minterpolate=fps=<A's rate>:mi_mode=mci`), same encoding;
   - `examples/moon/SOURCE.md` — source URL, date, NASA public-domain note, the exact commands used.
   Running the script twice gives identical files (deterministic encoder settings) or says why not.
2. `eval/expected.json` — the pass criteria from §5 as data: clip A (`fits:Moon`, |g − 1.62| ≤ 2·g_err, g_err ≤ 0.35),
   clip B (`none_fits`, k in 1.5 ± 0.25; `undetermined` soft fail, `fits:Moon` hard fail), wall run (`overall.label ==
   "impossible"`, the `wall` segment's `decide.state == "none_fits"` with |sigma| > 5, timescale verdict `normal`).
   The wall-run clip itself is **not** in the repo (third-party); `eval/expected.json` refers to it by a local path
   given on the command line.
3. `eval/check.py <run_dir> --case moon-A|moon-B|wallrun` → prints PASS / SOFT FAIL / HARD FAIL with the reasons, reads
   only `run_dir/analysis.json` and `run_dir/summary.json` (cost, turns, wall time), checks cost ≤ cap and wall time
   ≤ 30 min, and that at least one mask check was logged.
4. A guard test: nothing under `eval/` or `examples/*/SOURCE.md` is read by `physics_proof/` code (grep the package for
   `eval/` and `expected`), and the strings "1.62", "Moon", "slowed", "1.5" do not appear in
   `config/prompts/agent_system.md` if that file exists.

## Probes (tests, offline)
- `eval/check.py` on hand-made `analysis.json` files: one PASS, one SOFT FAIL, one HARD FAIL per case.
- `make_moon_clips.py --dry-run` prints the commands without downloading.
- (Run the real script once; commit `examples/moon/A.mp4`, `B.mp4` and `SOURCE.md` only if each is ≤ 10 MB.)

## Done when
Offline tests pass; the real script ran once and `examples/moon/` exists; `tasks/E1.report.md` written with the measured
frame rate and frame counts of A and B.
