# Task M7 — mask check

Spec: `SPEC.md` §3 "M7", §4 rule 1. Build only this module and its tests. Reuse `physics_proof/meta_client.py`
(`MetaClient.respond` with images and `json_schema`), `physics_proof/blocks.py` (`load_masks`, `mask_stats`),
`physics_proof/video.py` (`read_frames`), the ledger.

Why: the most common silent error in a measurement is a reference mask that covers more or less than the size that was
looked up (a body mask that includes a backpack; a car mask that misses the spoiler). A second pair of eyes with no
context of the run looks at the mask and says what it really covers.

## Build `physics_proof/mask_check.py`
- `MaskCheck(client, workspace, clip_path)` and `MaskCheck.run(npz, object_id, frames, claim) -> MaskCheckResult`, the
  agent's `mask_check(file, object, frames, claim)`:
  - `frames`: 1–4 frame numbers present in the npz; `claim`: one sentence from the agent ("the mask covers the whole
    person including the helmet").
  - For each frame, a crop around the object's bbox (padding 25 % of the bbox size, at least 32 px, clipped to the frame)
    rendered as a pair **plain | same crop with the mask tinted and outlined**, scaled so the pair is ≤ 1024 px wide.
    All pairs stacked into one sheet saved as `workspace/mask_checks/<npz-stem>.<object>.<n>.png` (kept for the page).
  - One Spark call with **no context of the run**: a short fixed instruction (in `config/prompts/mask_check.txt`), the
    sheet, and the claim. Strict JSON schema answer: `{inside: str, outside: str, covers: str, verdict: one of
    agrees | covers_more | covers_less | different_object | cannot_tell, reason: str}`.
  - Parse defensively (Spark may wrap the JSON in text; reuse what M4 learned).
  - Log every check to `workspace/mask_checks.jsonl` (npz, object, frames, claim, answer, cost) and keep an in-memory
    list so a later `finish` can ask `has_check(npz, object_id)`.
  - `MaskCheckResult`: the answer fields, `sheet` path, `cost_usd`, `text()` ≤ 800 characters.
  - Limit per run (default 4 checks); the 5th is refused without an API call.

## Probes (tests)
Fixtures are synthetic (draw them with Pillow/numpy in the test or a small script, commit the result):
`tests/fixtures/maskcheck_clip.mp4` — 10 frames, a red box with a blue handle on top, moving slowly on a grey
background; two npz files: (a) mask = box + handle, (b) mask = box only.
Offline:
1. The sheet for 4 frames exists, is ≤ 1024 px wide, and each pair's right half differs from the left only inside the
   tinted/outlined area.
2. Frames not in the npz, 0 or 5 frames, an unknown object id → clear errors, no API call.
3. The limit refuses the 5th check with no client call; `has_check` works.
4. A fake client returning JSON wrapped in prose is parsed.
API (`-m api`, < $0.01 total): claim "the mask covers only the red box" — on (a) the verdict is `covers_more` and
`covers` or `inside` mentions the handle; on (b) the verdict is `agrees`.
