# Task M2 — Video

Spec: `SPEC.md` §3 "M2. Video" and §4 rule 4 ("time is measured, not assumed"). Build only this module and its tests.
M1 (`physics_proof/meta_client.py`, `ledger.py`) is done; M2 makes no API calls.

## Build `physics_proof/video.py`
- `probe(path) -> VideoInfo`: width, height, fps as an exact `Fraction` (from the stream's average frame rate, not the
  container field rate), frame count (counted by decoding when the container does not say), sample aspect ratio (SAR)
  and display aspect ratio as `Fraction`s (1:1 when absent), duration in seconds, codec, pixel format. Use `ffprobe`.
- `read_frames(path, indices) -> dict[int, np.ndarray]`: exact frames by index (H×W×3 uint8, RGB, the stored pixel grid).
  Frame N must be the N-th decoded frame (0-based), whatever the timestamps. Short clips (≤ 2 min) may be decoded once
  into a cache; do not seek by time.
- `frame_diffs(path) -> np.ndarray`: mean absolute difference between consecutive frames (length = frames − 1). Used to
  find duplicated or interpolated frames; also `duplicate_runs(diffs, threshold) -> list[tuple[int, int]]`.
- `contact_sheet(path, frames, *, out, tile_width=320, columns=None, crop=None) -> Path`: up to 30 tiles in a grid; each
  tile labelled `f<index>` in its top-left corner; **labels are drawn after the final resize** of the tile, white text on
  a dark box, at least 14 px tall in the saved image. `crop=(x1, y1, x2, y2)` is in original pixel coordinates and is
  applied before resizing (this is the "zoom"). Optional `overlay(frame_index, tile_image, scale)` callback lets later
  modules draw masks or points; the callback receives the scale factor from original to tile pixels.
- `normalize(src, dst) -> VideoInfo`: H.264 (`libx264`, `yuv420p`, constant frame rate at the source's rate), no audio,
  no metadata, **same frame count and same frame order** as the source, **same pixel grid** (no resize, so mask and
  pixel coordinates stay valid; odd sizes are padded by one pixel on the right/bottom), SAR carried over in the stream.
  Use `ffmpeg` with flags that keep every frame (no dropping or duplicating).
- Pillow is allowed for drawing. This ffmpeg has no `drawtext` filter.

## Probes (tests, offline)
1. A synthetic clip: 120 frames at 30000/1001 fps, each frame shows its index as large digits (draw the digits with
   Pillow on numbered PNGs, then encode the PNG sequence with ffmpeg). `read_frames` of every 10th frame returns the
   right digits (compare against the source PNGs: mean absolute difference below a small threshold, or a simple digit
   template match — no OCR library needed).
2. `probe` on that clip: fps == Fraction(30000, 1001), frame count 120, duration within one frame of 120 × 1001 / 30000.
3. A copy of the clip with SAR 200:219 (`setsar`) reports SAR 200/219 and the matching display aspect.
4. `normalize` of an MPEG-2 or MJPEG version of the clip: same frame count, same width/height, frame N of the output
   still shows digit N (spot check every 10th frame), SAR preserved.
5. A clip with planted duplicates (frames 30–32 identical): `duplicate_runs(frame_diffs(...))` finds exactly that run.
6. `contact_sheet` with 30 tiles at `tile_width=160`: the file exists; for each tile the label box region is present
   (dark box with bright pixels) and its height in the saved image is ≥ 14 px; with `crop` the tile shows only the
   cropped region (check against the source frame's crop).
