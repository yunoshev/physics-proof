# Task M5 — Python sandbox (+ one small fix in M6)

Spec: `SPEC.md` §3 "M5. Python sandbox" and §2 (principles). Build only this module, its tests, and the small M6 fix
below. M1, M2 and M6 (`physics_proof/blocks.py`, top-level `blocks.py`) are done. No API calls in this task.

The agent (Spark) will write Python to measure things in a video. Its code runs on the maintainer's Mac, so this module
is the security boundary: two independent layers, each tested on its own.

## Build `physics_proof/sandbox.py`
- `review(code) -> list[Problem]` — static check with `ast` (each problem: line, rule, message). Refuse:
  - imports outside an allowlist: `numpy`, `scipy`, `PIL`, `matplotlib`, `blocks`, `math`, `cmath`, `statistics`,
    `json`, `csv`, `re`, `fractions`, `decimal`, `random`, `itertools`, `functools`, `collections`, `dataclasses`,
    `typing`, `pathlib`, `io`, `textwrap`, `string`, `time`, `datetime`, `subprocess` (see below);
  - `eval`, `exec`, `compile`, `__import__`, `importlib`, `getattr` on modules with a dynamic name, `os.system`,
    `os.popen`, `os.exec*`, `os.spawn*`, `ctypes`, `socket`, `urllib`, `http`, `requests`;
  - `subprocess.*` unless the first element of the argument list is the literal string `"ffmpeg"` or `"ffprobe"`, and
    never with `shell=True`;
  - string literals that are file-system paths outside the workspace: absolute paths (`/…`), `~`, or any `..` segment.
    **URLs (`http://`, `https://`) inside strings are data and are allowed.**
- `run_python(code, workspace, *, timeout_s=60) -> SandboxResult` — if `review` finds problems, do not run; return
  them. Otherwise save the code as `workspace/scripts/NNN.py` and run it:
  - with the project's virtualenv interpreter in isolated mode (`-I`), current directory = workspace, and a small
    runner of ours that puts the directory of `blocks.py` on `sys.path` and then runs the script (so `import blocks`
    works under `-I`);
  - with a **clean environment**: only `PATH` (system bins + the ffmpeg directory), `HOME` = workspace,
    `TMPDIR` = `workspace/tmp`, `MPLBACKEND=Agg`, `MPLCONFIGDIR` inside the workspace. No `META_API_KEY`, no other
    variables of the parent process;
  - inside macOS `sandbox-exec` with a profile generated per run: no network at all; file writes only inside the
    workspace; reads of the user's home directory denied except the workspace, the virtualenv, the interpreter's install
    directory and the package directory needed for `import blocks`; process execution allowed only for the interpreter,
    `ffmpeg` and `ffprobe`. Check how Seatbelt resolves overlapping allow/deny rules and test it;
  - killed (whole process group) after `timeout_s`.
  `SandboxResult`: `ok`, `refused`, `problems`, `exit_code`, `stdout` and `stderr` (each truncated to 8 000 characters
  with a note), `seconds`, `images` — up to two PNG/JPG files that this run created or changed in the workspace (newest
  first), `script` path.

## Probes (tests, offline)
Test each layer **separately**: for the sandbox layer call the runner with the review switched off (a test-only flag).
1. Review refuses: `import socket`, `urllib.request.urlopen(...)`, `open("/etc/passwd")`, `open("../x")`, `"~/x"`,
   `subprocess.run(["sh", "-c", "ls"])`, `subprocess.run("ffmpeg ...", shell=True)`, `eval("1")`, `__import__("os")`.
   Review allows: a string containing `https://example.com/a.png`, `subprocess.run(["ffprobe", "-v", "error", "clip.mp4"])`,
   numpy/scipy/matplotlib code, `import blocks`.
2. Sandbox (review off): opening a TCP socket to 1.1.1.1:443 fails; writing to `$HOME/sandbox_probe.txt` (path built at
   run time) fails and the file does not exist afterwards; reading a file in the real home directory outside the workspace
   (create one in the test, outside the workspace) fails; `subprocess.run(["/bin/sh", "-c", "echo hi"])` fails;
   `os.environ` printed by the code contains no `META_API_KEY` even when the parent has it set.
3. A loop that runs 61 s with `timeout_s=60` is killed; `seconds` < 65 (use `timeout_s=2` and a 5 s loop to keep the
   test fast, plus one marked `slow` test with the real 60/61 s values that is skipped by default).
4. Code that plots with matplotlib and saves `plot.png` returns it in `images`; code that writes three images returns the
   two newest.
5. `import blocks` works inside the sandbox and `blocks.fit_parabola` runs on a small array.
6. `ffprobe` on a clip inside the workspace works inside the sandbox.
