# M9 report — analysis schema and validator

## Built
- `config/analysis.schema.json` — draft 2020-12, `type: world-g`, version 1; all 13
  sections (`clip` … `page_texts`); moving-camera `scale` via `anyOf`; `source_url`/
  `quote` nullable; `second`/`apex`/`timescale` nullable; unknown fields allowed.
- `physics_proof/schema.py` — `Issue(path, message)`, `validate(analysis, *,
  clip_frames, fps)`, `combine(verdict, timescale)`, `schema_doc()`, `load_schema()`.
  Required/type/range checks; duration within half a frame; rise within 2 %/0.02 m;
  `decide` recomputed with `blocks.decide` (state, consistent, k ±1e-6); overall vs
  `combine`. Never re-implements the verdict.
- `scripts/make_m9_fixtures.py` — generator; decide/overall values come from
  `blocks.decide`/`combine`, so fixtures are consistent by construction.
- `tests/fixtures/analysis_ball.json` — ball tossed on Earth, image frame, fits Earth.
- `tests/fixtures/analysis_ramp.json` — skater up a vertical ramp, moving camera,
  `kind: wall`, 4.0 ± 0.5 vs 9.81, timescale normal → `impossible`; `second` set.
- `tests/test_schema_m9.py` — 16 tests.

## Probe coverage
1. Both fixtures validate with zero issues.
2. Schema-walked required list (70+ paths, `$ref`/`anyOf` resolved): each removal
   gives an issue at that exact path; every path covered by ≥ 1 fixture.
3. Tampered `verdict.state`, `flights[0].decide.k`, `duration_s`, `rise_m`, frame 999
   in track, wrong `overall.label` each rejected with a readable message.
4. `combine`: fits→world, undetermined, normal→`impossible`, none→`none_fits` with
   ×1.57, slow-consistent→`retimed`; one sentence each.
5. `schema_doc()` 1699 chars, names all 15 top-level keys, built from the schema file.
