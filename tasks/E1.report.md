# E1 report — acceptance clips and the eval checker

## Built
- `scripts/make_moon_clips.py`: downloads `a16salute.mpg` (found via the
  `a16salute.mpg` link on `https://www.apollojournals.org/alsj/a16/video16.html`,
  direct file `.../a16/a16salute.mpg`, 2765560 bytes), checks size (min 2 MB)
  and decodability (`probe` + first/last frame decode), writes `examples/moon/`
  `A.mp4` (H.264, yuv420p, CRF 18, no audio/metadata, CFR at probe fps),
  `B.mp4` (`setpts=1.5*PTS,minterpolate=fps=<A rate>:mi_mode=mci`), `SOURCE.md`
  (URL, date, NASA public-domain note, exact commands).
- `eval/expected.json`: SPEC §5 criteria as data (caps + per-case thresholds).
- `eval/check.py <run_dir> --case …`: stdlib-only; reads only the two run files;
  prints PASS / SOFT FAIL / HARD FAIL with reasons; exits 0/1/2 (3 on bad files).
- `tests/test_e1.py`: 15 tests (see below).

## Measured values (real run 2026-10-27, ffmpeg 9.0.2)
- Source: 352x240, fps 30000/1001 (29.97), 466 frames, SAR 200/219.
- A.mp4: 30000/1001 fps, 468 frames, 2290483 bytes (CFR re-encode adds 2 frames
  at the tail vs 466 decoded; same behaviour as `video.normalize`).
- B.mp4: 30000/1001 fps, 700 frames (≈1.5x), 2232458 bytes.
- Both video-only H.264/yuv420p, no source metadata; rerun is bit-identical
  (sha256 match). Both ≤ 10 MB, so committable.

## Probe coverage
- `check.py` PASS/SOFT/HARD per case: hand-made runs via subprocess —
  moon-A (fits:Moon / undetermined / fits:Earth), moon-B (none_fits k=1.5 /
  undetermined / fits:Moon), wallrun (impossible+wall+normal / slow timescale
  / no wall segment); plus cost-over-cap and missing-mask-check HARD FAILs.
- `--dry-run` prints both ffmpeg commands (incl. setpts/minterpolate) offline.
- Guard: no `eval/`, `expected.json` or `SOURCE.md` reference in
  `physics_proof/`; `agent_system.md` absent (M8 owns it) so prompt check vacuous.
