## Probes covered
1. 120-frame 320x240 clip at 30000/1001 fps with Pillow digits: every 10th
   frame matches its source PNG (MAD < 5; observed max 0.27).
2. `probe` gives fps 30000/1001, 120 frames, duration within one frame.
3. SAR clip reports SAR 200/219 and DAR = SAR·W/H exactly.
4. `normalize` of MPEG-2 and MJPEG copies: H.264/yuv420p/CFR, same count,
   size, rate, digit order; SAR 200/219 survives byte-exact.
5. Planted duplicates (frames 30–32) found as exactly `[(30, 32)]`.
6. 30-tile sheet at 160 px: every label box present, 25 px tall (≥ 14);
   `crop` shows only the cropped region; overlay hook receives the scale.

## Notes
- Frame reads decode the whole stream once (rawvideo, passthrough, short
  clips cached); frame N is the N-th decoded frame, never sought by time.
- No `drawtext` in this ffmpeg, so labels are Pillow text on a black box.
- This ffmpeg's `setsar` rounds 200/219 to 21/23, so the fixture SAR is set
  with `h264_metadata`, and `normalize` passes SAR via `-x264-params`.
- MPEG-2 only stores a fixed aspect table, so its fixture is 1:1; the
  `nb_frames`-less .mpg exercises the decode-to-count fallback.
- Odd sizes are padded one pixel right/bottom in `normalize` (tested).
