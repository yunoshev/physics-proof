# M4 report — search tool with a blindness filter

## Built
- [config/blindness.json](/Users/ayunoshev/Projects/Personal/physics-proof/config/blindness.json): word lists (always-refuse, event, quantity) + regexes; matching is case-insensitive.
- [physics_proof/search_tool.py](/Users/ayunoshev/Projects/Personal/physics-proof/physics_proof/search_tool.py): `SearchTool(client, workspace, *, limit=6)`, `run()`, `check_query()`, `filter_answer()`, `SearchResult` with compact `text()` (≤1500 chars, every source URL). One Spark call with `web_search`, short instruction, strict `{facts: [{text, source_url, quote}]}` schema (≤5). Every call logged to `workspace/search.jsonl`.
- [tests/test_search_tool.py](/Users/ayunoshev/Projects/Personal/physics-proof/tests/test_search_tool.py): offline probes plus the opt-in API probe.

## How each probe is covered
1. 20 queries: quantity words (height, speed, …) refuse only with an event word (jump, this, video, …); authenticity words (fake, slowed, frame rate, world record, in the air, …) refuse alone. All 20 exact.
2. `filter_answer`: "jump reached 0.5 m" cut (measurement + event), "clip is fake" cut, "PLSS is 26 inches tall" kept; cuts logged with reasons.
3. Limit: with `limit=2` the third `run()` is refused, fake client shows 2 calls.
4. Log: one JSON line per call with query, decision, cut count, sources, cost.
5. API (`-m api`): "standard gravity value in m/s^2" returned 1 cited fact (Wikipedia, quote in `text()`); ledger line with `searches = 1`; cost $0.0036 < $0.01.
