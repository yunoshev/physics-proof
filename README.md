# physics-proof

**Is this video physically real? Give it the video, get back a proof.**

physics-proof turns a short video into an interactive page that tests one physical claim in it — for example, how fast
things fall — measures it from the footage, compares it with what physics predicts, and gives a verdict with an honest
error bar. Measurements are drawn over the video itself: masks, the tracked point, the fitted parabola, a scale bar and
"ghost" trajectories of the same motion on Earth and on the Moon.

The investigation is run by an agent: **Muse Spark** watches the clip, decides what can be proven, asks **SAM 3.1** to
segment what it needs, looks up reference sizes on the web, writes and runs the measurement code in a sandbox, has a
second, context-free Spark check its masks, and assembles the page with a fixed player. All model calls go through the
**Meta Model API**.

First case: the Apollo 16 "jump salute" (NASA, public domain) and a slowed copy we make ourselves. The page should say
"Moon" for the original and "slowed about ×1.5" for the copy.

## Status

Spec stage. The specification is in [SPEC.md](SPEC.md); the code is written module by module against it.

## Built during the hackathon

This repository was started on 27 October 2026 for the **Meta Global AI Developer Hackathon** (26 October – 4 November
2026). Everything in it is new work made during the event. The code is written by Spark through **Muse Code** from the
spec; commits with code generated by Muse Code are tagged `[muse-code]`; modules the maintainer wrote by hand are listed here.

## Meta tools used

| Tool | Role |
|---|---|
| Muse Spark 1.3 (Meta Model API) | the orchestrating agent; independent mask checks; web search for reference sizes |
| SAM 3.1 (Meta Model API) | text-prompted video segmentation on the agent's request |
| Muse Code | writes the harness from the spec |
| Muse Spark Open (optional) | open-weights path through a partner, if credits allow |

## Footage and rights

Example clips are NASA public-domain footage and fakes we derive from it. Third-party videos are never committed: the tool
runs on any video you have the right to analyse.
